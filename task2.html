Bootstrap Responsive Columns (12-Column Grid)

This layout utilizes Bootstrap’s 12-column grid system with the responsive classes col-12 col-md-6 col-lg-4. On desktop each card occupies 4 columns (3 cards per row). On tablet screens each card occupies 6 columns, placing 2 cards on the first row and 1 card on the second row. On mobile, all columns stack at 12 columns wide.

Column 1

Bootstrap Grid Basics

The Bootstrap grid is divided into 12 fractional columns per row. Containers and rows align items cleanly across pre-set breakpoints.

Column 2

Responsive Breakpoints

By specifying col-md-6 and col-lg-4, the layout adjusts automatically when passing the 768px (medium) and 992px (large) thresholds.

Column 3

Auto Wrapping

When column sums exceed 12 within a single row, excess columns cleanly wrap to the next line without any manual float or clearing rules.

Current Grid Configuration:
  • Desktop (≥ 992px): col-lg-4 → 4 + 4 + 4 = 12 (3 side by side)
  • Tablet (768px - 991px): col-md-6 → 6 + 6 = 12 (Row 1), 6 (Row 2)
  • Mobile (< 768px): col-12 → 12 columns (1 per row, stacked)
